# 🚲 Chill Rider

**Chill Rider** is a lo-fi inspired, 3D bicycle journey designed for relaxation. Pedal through an infinite sunset, enjoy the pastel-colored low-poly world, and find your flow.

![Sunset Vibe](https://images.unsplash.com/photo-1476673160081-cf065607f449?auto=format&fit=crop&q=80&w=1000)

## ✨ Features
- **Sunset Aesthetic:** A procedural "Golden Hour" world with peach-colored fog and warm lighting.
- **Dynamic Physics:** Smooth bicycle movement with realistic leaning and weight distribution.
- **Infinite Road:** A stylized path that generates as you pedal.
- **Lofi Radio:** Built-in radio to set the perfect mood for your ride.

## 🎮 Controls
- **W / S**: Pedal Forward / Backward
- **A / D**: Steer & Lean
- **SPACE**: Brake
- **MOUSE**: Interact with HUD

## 🛠️ Tech Stack
- **Engine:** [Three.js](https://threejs.org/)
- **Bundler:** [Vite](https://vitejs.dev/)
- **Styling:** Vanilla CSS (Glassmorphism & Modern Typography)

## 🚀 Getting Started
```bash
# Clone the repository
git clone [YOUR_REPO_URL]

# Install dependencies
npm install

# Run development server
npm run dev
```
